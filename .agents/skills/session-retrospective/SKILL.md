# セッション全体の振り返り

1. 最初の依頼から追加指示、承認、計画、変更、検証までセッション全体を読み直す。依頼と計画の全項目を完了・未完了・未確認に照合する。
2. 実行したcommit、入力、環境、検査結果、CIの状態を確認する。失敗した試行、未実行、見え方や実環境で未確認の点を隠さず、変更と検証を分けて報告する。
3. 手戻り、曖昧な判断、重複作業、効いた手順を根拠とともに整理する。原因は実際の到達経路を確かめ、推測を確定事項にしない。
4. 次回の改善案を効果、費用、リスク、推奨順で提案する。規約やスキルの改善は提案にとどめ、承認なしに統治文書を書き換えない。
5. 残件、担当、停止条件、次の判断、証拠の場所を引き継ぐ。完了報告に変更、検証、未確認、改善案を含め、成果物や未保存の記録を保全する。
