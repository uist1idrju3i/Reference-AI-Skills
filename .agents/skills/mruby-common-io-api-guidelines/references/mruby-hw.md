# mruby hw-*とMPIGの差分

対象はmruby 4.1.0-rc2、commit `c17ffcc24190b71682bc611fa80053bb252ad482`です。**プレリリースの参考実装であり、標準ではありません。** 以下は固定commitのmrblibと共通srcに定義・登録されたRuby methodの静的比較です。constructorも含め、継承する一般的なObject methodは除きます。MPIGの基準は[契約表](mpig.md)です。実機での精度・通信・例外到達を実測したものではなく、戻り値やエラーのうちHAL依存のものは区別します。

## 定数・native境界と未確認

GPIOの6定数名はMPIGに対応しますが、[両GPIO port](https://github.com/mruby/mruby/blob/c17ffcc24190b71682bc611fa80053bb252ad482/mrbgems/hw-gpio/ports/rp2040/gpio.c)ではHIGH_ZとOPEN_DRAINが未実装のままです。[もう一方のport](https://github.com/mruby/mruby/blob/c17ffcc24190b71682bc611fa80053bb252ad482/mrbgems/hw-gpio/ports/esp32/gpio.c)も同様です。Rubyの定数やmethodが存在するだけで、電気的な動作まで対応したとは判定しません。

UARTの定数はPARITY_NONE/EVEN/ODD、FLOW_CONTROL_NONE/RTS_CTSで、MPIGのNONE/EVEN/ODD/RTSCTSとは異なります。SPIのMSB_FIRST/LSB_FIRST名は一致しますが、DEFAULT_FREQUENCYは100000です。PWMの内部@pin/@frequency/@duty、I2CのDEFAULT_FREQUENCY=100000とDEFAULT_TIMEOUT=500は標準への追加実装です。

SPI.newの必須keyword数はコメントやREADMEではなくCの `mrb_kwargs {8, 7, ...}` と、[mrb_kwargsのrequired定義](https://github.com/mruby/mruby/blob/c17ffcc24190b71682bc611fa80053bb252ad482/include/mruby.h)、[mrb_get_argsの必須keyword処理](https://github.com/mruby/mruby/blob/c17ffcc24190b71682bc611fa80053bb252ad482/src/class.c)を照合しました。先頭7名を必須として探索するので、周波数などのC既定値は通常の省略呼出しで利用できるとは限りません。この差分は静的に確認したもので、当該hw gemの実行による再現は行っていません。

I2C/SPIのbyte出力はIntegerをuint8_tへcastし、Arrayの要素型は確認しますが0〜255の範囲は明示検査しません。addressの7bit範囲、転送長・加算の上限、timeoutの負数、bufferの解放を含む異常系を導入先で検査します。UART/I2C/SPIのnative helperはMPIGの標準APIとして公開しません。低レベルのportごとの全動作はこの比較の対象外です。

MPIGにない戻り値や例外は、それだけで規格違反とはしていません。反対に、UARTの待機、GPIO.write_atの例外、PWM.period_us(0)、SPIの既定周波数・write戻り値・transfer引数は、標準と同じものとして移植しないでください。
